## 数据流图

### 单次对话请求的完整流程

```
客户端
  │
  │ 1. HTTPS POST /v1/chat/completions
  │    {"user_id": "student_001", "message": "老师，这道题我不会"}
  ▼
Nginx
  │
  │ 2. 反向代理 + SSL 终止
  ▼
Gateway (C++)
  │
  ├─ 3a. Session 路由
  │      查找 user_id → Session 对象
  │
  ├─ 3b. L1 缓存读取
  │      获取最近 12 轮对话
  │
  ├─ 4. gRPC → Inference Service (并行)
  │   │
  │   ├─ BERT 情绪分类
  │   │  输入: "老师，这道题我不会"
  │   │  输出: {emotion: "confused", valence: -0.3, arousal: 0.4}
  │   │
  │   └─ 人脸情绪识别 (如果有图片)
  │      输入: 图片数据
  │      输出: {emotion: "focused", valence: 0.2, arousal: 0.5}
  │
  ├─ 5. gRPC → Persona Service
  │   │  输入: {user_emotion, ai_emotion, l1_messages, persona_config}
  │   │
  │   ├─ 情绪状态机更新
  │   │  valence: -0.1 → -0.2 (负面情绪增强)
  │   │  arousal: 0.3 → 0.4 (唤醒度提升)
  │   │
  │   ├─ 动态 Hint 生成
  │   │  "学生当前有些困惑，需要耐心引导"
  │   │
  │   └─ Prompt 构建
  │      输出: 完整的 Prompt (包含人格、记忆、情绪 Hint)
  │
  ├─ 6. gRPC → Memory Service (异步，可选)
  │      如果 L1 缓存满 → 触发压缩
  │      L1 → L2 结构化状态提取
  │
  ├─ 7. gRPC → RAG Service (可选)
  │      如果需要知识库 → 向量检索
  │      输出: 相关知识片段
  │
  ├─ 8. 调用 LLM (云端或本地)
  │      输入: Prompt + RAG 上下文
  │      输出: "这道题我们可以这样理解..."
  │
  ├─ 9. 更新 L1 缓存
  │      添加本轮对话到缓存
  │
  └─ 10. 返回响应
       {"role": "assistant", "content": "这道题我们可以这样理解..."}
       │
       ▼
     Nginx
       │
       ▼
     客户端
```

## 故障隔离示意图

### 场景 1：推理服务崩溃

```
客户端请求
    │
    ▼
Gateway
    │
    ├─ gRPC → Persona Service ✓ (正常)
    │
    ├─ gRPC → Inference Service ✗ (崩溃/超时)
    │   │
    │   └─ 降级策略触发
    │      • 返回缓存的情绪结果
    │      • 或使用默认情绪 (neutral)
    │
    └─ 继续处理，返回响应 ✓
       (用户可能收到"系统繁忙"或略微不准确的情绪判断)
```

### 场景 2：记忆服务崩溃

```
客户端请求
    │
    ▼
Gateway
    │
    ├─ gRPC → Persona Service ✓ (正常)
    │
    ├─ gRPC → Inference Service ✓ (正常)
    │
    ├─ gRPC → Memory Service ✗ (崩溃/超时)
    │   │
    │   └─ 降级策略触发
    │      • 跳过 L1→L2 压缩
    │      • 只使用 L1 缓存 (最近 12 轮)
    │
    └─ 继续处理，返回响应 ✓
       (用户体验无明显影响，只是长期记忆不更新)
```

### 场景 3：网关服务崩溃

```
客户端请求
    │
    ▼
Nginx (负载均衡)
    │
    ├─ Gateway-1 ✗ (崩溃)
    │
    └─ Gateway-2 ✓ (正常)
       │
       └─ 继续处理 ✓
          (用户无感知，Nginx 自动切换到健康实例)
```
